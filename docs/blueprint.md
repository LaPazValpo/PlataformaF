# **App Name**: Paz Final Central

## Core Features:

- Data Dashboard: Visualize key metrics from 'prospects', 'proposals', 'sales' collections, such as the number of prospects, conversion rates, and total sales, displaying them using charts and graphs.
- Salesperson Performance Overview: Aggregate and display sales performance data for each salesperson from the 'sellers' and 'sales' collections, showing metrics like total sales, conversion rates, and commission earned, in a sortable table.
- Inventory Tracker: Monitor real-time inventory levels for services and products, based on data from the 'inventory' collection, displaying items, quantity in stock, and low stock alerts.
- Content Generation Tool: An AI tool that uses existing testimonials as a tool to either suggest improvements to existing testimonials or craft entirely new testimonials based on themes derived from current testimonials, aiming to enhance sales and marketing materials.
- Service Package Customizer: Display service package options and allow potential clients to customize service packages. Each of the options come from the 'servicePacks' collection.
- Virtual Chapel Showcase: Display example virtual tomb designs to inspire clients. Virtual Tombs are from the 'virtualTombs' collection.

## Style Guidelines:

- Primary color: Deep navy blue (#2E3A59) to convey trust and reliability in a sensitive field.
- Background color: Light gray (#F0F4F8), offering a clean and calm visual space.
- Accent color: Soft gold (#A98D6C) to add a touch of elegance and highlight important data.
- Body and headline font: 'PT Sans', a modern, humanist sans-serif font that will maintain legibility.
- Simple, clean icons for representing data and navigation.
- A clean, well-organized layout, prioritizing clear data visualization and ease of navigation. Employ a grid system to align the dashboards and tools for a seamless, responsive experience.
- Subtle transitions and animations to enhance user experience without distraction.
